# VAPT — Vulnerability Assessment & Penetration Testing

A structured, hands-on knowledge base documenting authorized penetration-testing labs, Hack The Box machines, methodology, tooling, findings, and lessons learned.

## Current sections

- [Hack The Box (HTB)](HTB/README.md) — machine walkthroughs and technical notes.

## Documentation principles

- Record findings from actual lab evidence and explain the reasoning behind each step.
- Keep commands, observations, and conclusions clearly separated.
- Redact passwords, tokens, and flag values from public documentation.
- Use screenshots as supporting evidence, with sensitive values removed where appropriate.
- Perform testing only against systems you own or are explicitly authorized to assess.
