# Hack The Box

This section documents hands-on Hack The Box machines completed for learning and portfolio development.

## Machines

| Machine | OS | Difficulty | Status | Key techniques |
|---|---|---|---|---|
| [Cap](Cap/README.md) | Linux | Easy | Pwned | Nmap, IDOR, PCAP analysis, FTP credential exposure, SSH credential reuse, Linux capabilities |

## Write-up format

Each machine folder aims to include:

- Machine overview and scope
- Reconnaissance and service enumeration
- Evidence-driven exploitation notes
- Initial access and privilege escalation
- Findings, impact, and remediation ideas
- Supporting screenshots and command references

**Lab safety:** These notes are for authorized HTB practice. Do not apply techniques to systems without explicit permission.
